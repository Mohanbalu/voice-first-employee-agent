# API Documentation

RESTful and WebSocket API specifications for the Voice-First Employee Assistant.

## Endpoint Overview
- `/api/v1/auth`: Authentication and JWT token issuance
- `/api/v1/chat`: Conversational agent endpoint (voice/text)
- `/api/v1/documents`: Policy ingestion and retrieval status
- `/api/v1/tickets`: HR/IT ticket management and status
- `/api/v1/location`: Indoor maps and routing directions
- `/api/v1/calendar`: Meeting schedules and room availability
- `/api/v1/tasks`: Action items and reminders
- `/api/v1/timesheet`: Timesheet submissions and assistant
- `/api/v1/messages`: High-priority communication notifications
- `/api/v1/notifications`: Real-time system notifications
